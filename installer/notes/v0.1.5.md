clip-mcp 0.1.5：AI 會知道你的電腦跑聽打要多久，慢的電腦可以選「快速聽打」；「連接 AI」頁也修好了。

已經裝了舊版的話，開啟編輯器，左下角會出現更新提示，按下就會更新；也可以直接執行下面的安裝檔，會覆蓋過去，專案和素材都會保留。

## 新功能

- **AI 知道這台電腦有多快**：聽打（語音辨識）在不同電腦上快慢差很多——有 NVIDIA 顯示卡的電腦一小時的影片幾分鐘就好，只靠處理器的筆電可能要半小時以上。AI 現在一連上就知道你的電腦屬於哪一級、大概要等多久，分析之前會先跟你說。跑過幾次之後，時間會改用這台電腦實際量到的速度。
- **快速聽打**：在比較慢的電腦上、或影片很長時，AI 會先問你要用「精準」還是「快速」。快速大約省一半時間，但錯字比較多、剪接點比較不準。之後想要精準的，跟 AI 說一聲就會重新聽打；已經是精準的不會被換成快速的。第一次用快速聽打時會再下載約 500 MB 的模型。
- **「快速聽打」標籤**：素材頁上，用快速模式聽打的檔案會標出來，檢查字幕時可以多留意。
- **AI 會注意可能聽錯的字**：語音辨識沒把握的字，AI 會特別檢查，人名、產品名這類常聽錯的地方比較容易被改正。

## 修正

- **連接 AI 抓不到 Claude Desktop**：從 Microsoft Store 安裝的 Claude Desktop 設定放在不同的位置，之前會顯示「未安裝」。
- **連接 AI 有時抓不到 Claude Code**：Claude Code 是在登入 Windows 之後才裝的，編輯器可能找不到它；現在會去它的預設安裝位置找。
- **打開「連接 AI」頁會閃出黑色視窗**：檢查 Claude Code 時不再跳出命令提示字元視窗。

## 安裝

1. 下載下面的 `clip-mcp-setup-0.1.5.exe`，雙擊執行。
2. Windows 可能會跳出「Windows 已保護您的電腦」：這是因為安裝檔還沒有數位簽章。按「其他資訊」→「仍要執行」即可。
3. 安裝時需要網路：會下載 Python、clip-mcp 的元件和 FFmpeg（裝好後約 900 MB，視網速需要幾分鐘）。全部裝在 `%LOCALAPPDATA%\Programs\clip-mcp`，不需要系統管理員權限，也不會修改系統的 PATH。
4. 開啟「clip-mcp 剪輯」，到左邊的「連接 AI」選擇要讓哪個 AI 程式使用 clip-mcp。安裝程式不會自動修改任何 AI 程式的設定。

支援的 AI 程式：Claude Desktop、Claude Code、ChatGPT 桌面版（Codex 分頁）、Codex CLI、Gemini CLI、LM Studio、Cherry Studio、opencode。

第一次產生字幕時，會再下載約 1.6 GB 的語音辨識模型（會先問你）；第一次依意思找片段時，會下載約 130 MB 的搜尋模型。

## 移除

從 Windows 的「設定 → 應用程式」解除安裝「clip-mcp 剪輯」。它會先把這一份 clip-mcp 從每個 AI 程式的設定中移除，問你要不要刪除專案資料（會移到資源回收筒），再刪除程式。「影片\clip-mcp」裡的成品不會被刪除。Cherry Studio 例外：它的設定要到 Cherry Studio 的設定 → MCP 伺服器自己刪除。
